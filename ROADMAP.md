# Roadmap

Each feature ships with validation, tests, usage examples, and passing CI.

## Next

1. Timestamp support for explicit numeric timezone offsets.
2. File-based JSON comparison with clear structural differences.
3. Explicit Base64url support for web payloads.

## Delivered

- JSON compatibility with one leading UTF-8 byte-order mark.

- Cryptographically random UUID generation with bounded batch sizes.

- SHA-256 checksums for text, files, and piped bytes.

- UTF-8 Base64 encoding and strict decoding.

- JSON formatting, validation, and minification.
- URL component and HTML form value conversion.
- Unix timestamp and UTC date conversion.
