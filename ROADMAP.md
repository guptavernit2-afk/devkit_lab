# Roadmap

Each feature ships with validation, tests, usage examples, and passing CI.

## Next

1. SHA-256 checksums for text, files, and piped bytes.
2. Cryptographically random UUID generation with bounded batch sizes.
3. JSON input compatibility with UTF-8 byte-order marks from text editors.
4. Timestamp support for explicit numeric timezone offsets.

## Delivered

- UTF-8 Base64 encoding and strict decoding.

- JSON formatting, validation, and minification.
- URL component and HTML form value conversion.
- Unix timestamp and UTC date conversion.
